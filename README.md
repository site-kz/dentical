# AURA DENT — сайт стоматологии в Таразе

Готовый сайт для демонстрации клиентам: HTML, CSS и JavaScript без сборки и установки пакетов.

## Запуск
1. Распакуйте архив целиком.
2. Откройте папку taraz-dental в Visual Studio Code через File → Open Folder.
3. Откройте index.html в браузере двойным щелчком либо через расширение Live Server.

## Файлы
- index.html — услуги, пример цен, информация о клинике, адрес и форма.
- styles.css — дизайн и адаптация под телефоны.
- script.js — меню, проверка формы и подготовка сообщения в WhatsApp.
- assets/clinic.jpg — локальная фотография кабинета.

## WhatsApp
Уже подключён номер +7 776 663 23 30. Кнопки WhatsApp открывают чат. Форма собирает имя, услугу, желаемую дату и время, затем открывает готовое сообщение. Посетитель отправляет его самостоятельно. Сайт не проверяет свободные часы и не создаёт подтверждённую запись. Данные не сохраняются на сайте.

## Настройка под клиента
Название AURA DENT, адрес «ваш адрес», часы и цены редактируются в index.html. Номер WhatsApp замените в ссылках index.html и в константе WHATSAPP_NUMBER в script.js. Цвета находятся в начале styles.css в блоке :root.

Название, цены и описание клиники демонстрационные. Перед рабочим запуском замените их реальными сведениями и согласуйте содержание с клиникой. Фотография иллюстративная. Сайт не содержит вымышленных профилей врачей.

Шрифты Golos Text и Prata загружаются из Google Fonts при наличии интернета. Без сети используются Arial и Georgia. Фотография работает без интернета. Для перехода в WhatsApp нужен интернет.
